about=This plugin provides a guided workflow to convert LiDAR point clouds of single trees into 3D plants for the microclimate model ENVI-met. Supported inputs are LAS, LAZ, COPC, E57, PLY, PCD, OBJ, SBF and text files (XYZ, TXT, CSV, PTS) as well as point cloud layers already loaded in QGIS. A step-by-step wizard leads through loading, selecting the tree, filtering, trunk picking, scaling and rotating, voxelising at 1 m resolution, foliage, roots, physiology and export. Leaf area density can be calibrated with reference voxels or scaled to a target leaf area index (LAI) or a total leaf area; key figures are shown live. The root system is defined by shape, depth, radius and vertical distribution, with presets that cite their sources. A-gs parameters come from tree type presets or manual input. The tree is exported for ENVI-met 6 (JSON database) or ENVI-met 5.x (classic database), either as a single-plant file or directly into an existing project or user database, with automatic backup and plant ID management. All settings can be saved as a project file for reproducible results. Some formats need additional Python packages (laspy, lazrs, pye57, plyfile) that are not part of QGIS; the plugin shows what is missing and how to install it. See the README for details.
